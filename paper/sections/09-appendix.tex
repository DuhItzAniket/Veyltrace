\subsection{Predicate library}
\label{sec:app-predicates}

Table~\ref{tab:predicates} lists the ten predicates of \S\ref{sec:evidence}, as implemented in \vtkey{packages/faultloom/src/veyltrace_faultloom/predicates.py} and specified in docs/engines/06 §3.5; \vtkey{contracts/predicates.json} holds their names, parameter types, polarities and windows.
The subject is always implied and is never an argument.
The argument ranges are configuration (\code{predicates.<name>.<param>} in \vtkey{config/faultloom.yaml}), and the weights are \code{predicates.<name>.weight} in \vtkey{config/causentra.yaml}.
Before evaluation, a claim is rejected as \code{unknown_predicate} if its name is not in the library, as \code{unknown_entity} if a service argument is not a graph node, and as \code{bad_args} for any other missing, extra, mistyped or out-of-range argument, or an explicit subject (docs/engines/06 §3.5).

\subsection{Pinned external artefacts}
\label{sec:app-pins}

\paragraph{RCAEval}
The BARO and N-Sigma baselines run RCAEval's own \code{main.py} from \url{https://github.com/phamquiluan/RCAEval} at commit \texttt{90b63a46\allowbreak ac1e969f\allowbreak 1fa90153\allowbreak 18b51e45\allowbreak 5c62f8c4}, tag 1.12.0 of 6 November 2026 (\code{rcaeval.commit} in \vtkey{bench/baselines.yaml}; tag and date checked on GitHub, 27 November 2026).
They run in an isolated virtual environment installed from \vtkey{scripts/rcaeval/requirements.lock} by \vtkey{scripts/rcaeval/setup.py}, which checks out that commit.

\paragraph{Model}
The proposer model is \code{qwen3.5:9b}~\cite{qwen35card}, the Q4\_K\_M quantisation, with GGUF SHA-256 \texttt{02d45dc1\allowbreak cf451ba2\allowbreak 475ac33b\allowbreak 301c2dd8\allowbreak f985abe4\allowbreak c182ce04\allowbreak a1f2f5bf\allowbreak 0260278d} (\code{model.name} and \code{model.gguf_sha256} in \vtkey{config/llm.yaml}; quantisation and file size of 5,629,109,120 bytes in \vtkey{docs/team/ak.md}).
It is served by Ollama on localhost with a 16,384-token context (\code{runtime.num_ctx} in \vtkey{config/llm.yaml}).
The same file's \code{runtime.parallel} $= 1$ and \code{runtime.cache_prompt} $=$ false are recorded in each cassette entry but are not sent to Ollama (\vtkey{packages/llm/src/veyltrace_llm/ollama.py}), and no committed file records the server's \code{OLLAMA_NUM_PARALLEL}.
The configured fallback, \code{qwen3.5:4b}, is named by no file under \vtkey{bench/results/}.

RQ5's cost of the deterministic path (Table~\ref{tab:rq5}) comes only from the \code{veyltrace:off} rows of \code{re2-oracle-rq1-v1}, which the R-16 plan (GitHub issue \#45, decision 3) scheduled as one solo run at \code{results-code-v1} with nothing else heavy on the machine.
